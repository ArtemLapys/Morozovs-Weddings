# Morozovs Weddings Landing Page

Статический лендинг для размещения на GitHub Pages. Проект содержит:

- `index.html` — главную страницу
- `css/style.css` — стили
- `js/main.js` — плавная прокрутка навигации

## Запуск

Просто откройте `index.html` в браузере или разверните репозиторий на GitHub Pages.
